      Documentation gaps
      
    
      Questions the docs couldn't answer (and 👎 answers) are collected during the day. On each list's schedule the AI groups them, looks for the answer in the team's docs, repo code and chats, and drafts the missing section; the admins get an email. Review each draft: edit it if needed, then Add (saved like any update, with history) or Reject (it won't be proposed again). The AI only uses what it found; what it couldn't find is listed under "Needs your answer".

      Insights
      
    
      Every question, answer and feedback is saved as JSON (secrets scrubbed, users only as a hash). On the schedule below the AI analyses everything since the last report, the report is saved here and emailed to super admins, and the raw records are cleared so the next period starts fresh. Download the raw JSON any time before that.
